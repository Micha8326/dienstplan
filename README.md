# Dienstplan

Persönlicher Dienstplan als Web-App (PWA). Stationsplan fotografieren und von Claude erkennen lassen oder Dienste manuell eintragen. Monatskalender mit Stunden, Export als .ics, Backup als JSON.

Alle Daten bleiben im Browser (localStorage). Der Anthropic-API-Schlüssel wird nur lokal gespeichert und direkt an die Anthropic-API geschickt.

Ursprünglich entstanden in Micha8326/liqstorm-web unter /dienstplan/.
