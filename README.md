# Dienstplan

Persönlicher Dienstplan als Web-App (PWA). Dienste manuell per Antippen eintragen oder den Stationsplan fotografieren und im Browser per Texterkennung (Tesseract.js) auslesen lassen. Monatskalender mit Stunden, Export als .ics, Backup als JSON.

Keine KI-Anbindung, kein API-Schlüssel, kein Server. Alle Daten bleiben im Browser (localStorage).

Ursprünglich entstanden in Micha8326/liqstorm-web unter /dienstplan/.
